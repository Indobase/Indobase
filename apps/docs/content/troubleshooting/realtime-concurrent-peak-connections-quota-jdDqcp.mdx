The "Concurrent Peak Connections" quota refers to the maximum number of simultaneous connections to Indobase Realtime.

For example, if you have a chat application that uses Indobase Realtime and you have 100 users who are all connected and subscribed to the chat channel, then you would have 100 concurrent peak connections. Each client can connect to multiple Realtime channels (see: https://indobase.in/docs/guides/realtime/concepts#channels).

This quota applies to all Indobase projects, including self-hosted projects, but you can increase it depending on your use case. For hosted Indobase projects, select the plan that fits your Realtime usage and reach out if you need custom quotas. For those self-hosting Indobase, you can set those limits yourself by setting the `max_concurrent_users` field on the tenant record (see: https://indobase.in/docs/guides/self-hosting/realtime/config).

You can learn more about Realtime limits here: https://indobase.in/docs/guides/realtime/limits#limits-by-plan
