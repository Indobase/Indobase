# `@indobase/cloudflare-adapter`

Builder Gen 3 translation layer: agent execution runtime (CF OS, internal) → Indobase Workspace / Commands / Events / Project Runtime / Execution.

**Indobase owns** identity, projects, workspace, deploy, capabilities, billing, snapshots, AI orchestration.  
**CF OS is** an implementation detail for agent turns — never durable SoT.

See [`docs/BUILDER-GEN3.md`](../../docs/BUILDER-GEN3.md).

```bash
cd packages/cloudflare-adapter
pnpm install --ignore-workspace
pnpm test
```
