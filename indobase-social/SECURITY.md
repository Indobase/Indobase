# Security Policy

## Supported versions

Indobase Social supports the latest release on the Indobase deployment branches.
Use the latest published image when possible.

## Reporting a vulnerability

If you discover a security vulnerability in Indobase Social, please report it through the
[GitHub Security Advisory system](https://github.com/Indobase/Indobase/security/advisories/new)
or contact the Indobase team at security@indobase.in.

Please do not open a public issue for vulnerabilities that could put users at risk.

## Scope

In scope for this fork:

- The `indobase-social` application tree in Indobase/Indobase
- Official Indobase Social container images and deploy configs maintained by Indobase
- Integrations and plugins shipped with this tree

Out of scope:

- Third-party dependency issues unless Indobase Social’s use of the dependency is independently exploitable
- Issues that only affect the upstream Postiz project outside this fork (report those upstream)

## Disclosure

We will acknowledge reports, investigate, and coordinate fixes and disclosure as appropriate.
