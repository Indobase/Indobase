Indobase Video is an Indobase Marketing product. The browser editor and
timeline/export approach are inspired by the MIT-licensed OpenCut classic
editor ([OpenCut-app/opencut-classic](https://github.com/OpenCut-app/opencut-classic)).

## Upstream

- Project: OpenCut (classic)
- License: MIT (see `LICENSE`)
- Copyright: OpenCut contributors

The OpenCut rewrite (`OpenCut-app/OpenCut`) was evaluated and rejected as a
runtime base because it is still architecture/scaffold-level. This tree ships a
purpose-built Indobase Video v1 editor (import, timeline trim/split, text,
preview, WebM export, project-scoped autosave) with Studio SSO — not a
rebranded upstream binary.

User-visible product name in the shipped UI is **Indobase Video** only.
OpenCut / CapCut names must not appear in built frontend bundles.
